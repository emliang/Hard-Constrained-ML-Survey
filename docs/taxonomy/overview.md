
# Taxonomy Overview

Prediction is organized by the role of the constraint-handling mechanism in the deployed computation. Generation is organized by the sample-generation procedure, with its constraint mechanisms discussed within that procedure.

## Main branches

| Branch | Question |
|---|---|
| Hard-constrained prediction | How does a predictor return feasible decisions or labels? |
| Hard-constrained generation | How does a generator produce valid constrained samples? |
| Applications and benchmarks | How are feasibility, utility, and cost reported in practice? |
| Evaluation terminology | What kind of evidence supports a hard-constraint claim? |

The same mechanism can appear in several applications, and a hybrid paper can combine several roles. Classification and feasibility evidence are separate: belonging to a family does not establish a universal guarantee.
